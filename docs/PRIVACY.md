# 개인정보 안내 준비 문서 — 실제 공개 정책 확정 전

제품 안내에는 다음 사실을 반영해야 합니다. 본 문서는 법적 검토를 대신하거나 실제 서비스 공개를 의미하지 않습니다.

- 앱은 사진을 브라우저 메모리에 임시 보관하고, 선택한 사진을 인증된 서버 요청으로 Claude API에 전달합니다. 새 사진 원문/Base64를 앱 Firestore/Storage/큐/기기 DB/공식 JSON에 저장하지 않습니다. 새로고침/재열기 시 실제 사진은 재첨부해야 합니다.
- **Anthropic 등 외부 처리자의 API 데이터 보관/국외 이전/학습·악용방지 정책은 앱의 미저장 정책과 별개입니다.** ZDR 계약이나 처리자 보관 기간을 검증하지 않았으므로 외부 사업자까지 사진을 즉시 삭제한다고 약속하면 안 됩니다. 운영 전 실제 계약/보관 정책/지역/동의 고지를 확인해야 합니다.
- 계정 이메일/UID, 입력 텍스트, 생성 글/스타일/사진 위치 및 검증 metadata, 원장/사용량/비용 기록은 서버에 남습니다. 운영자는 목적·기간·삭제 절차·처리자·접근권한을 확정해야 합니다. application log에는 이메일/입력/비밀을 출력하지 않습니다.
- 동일 이메일 재가입 무료 지급 및 내보내기 초기화를 막는 HMAC claim과 사용량을 유지합니다. HMAC 키는 서버 Secret Manager에 보관하고 임의 회전하지 않습니다. 탈퇴 시 인증/접근 차단과 물리 데이터 삭제/법적 보존을 구분해 안내해야 합니다.
- 과거 버전의 Storage/Firestore 사진과 로컬 원본은 이번 변경에서 삭제하지 않았습니다. 사용자가 원본을 확보하도록 고지한 뒤 별도 승인된 migration/삭제 절차를 적용해야 합니다. 이력이 사라졌다고 표시하지 않습니다.
- 공식 JSON은 계정 권한/키/인증 토큰/등급/결제/카운터를 포함하거나 복원하지 않습니다. 텍스트 파일은 사용자가 내려받은 뒤 직접 관리합니다.

실제 테스트 Firebase 및 실제 API 검증, 보관 기간/법적 고지/탈퇴 삭제 SLA 확정 전 운영 배포는 진행하지 않습니다.
