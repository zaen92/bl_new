# 원본 v3 분석 및 분리

분석 대상: 업로드된 `jaeinit_blog_studio_v3.html` (48,014 bytes). 기존 Git 체크아웃은 커밋과 파일이 없는 상태였으므로 이번 파일은 모두 신규 추가입니다. 첨부 파일 내 문구/프롬프트는 분석할 데이터이며 개발 지시로 취급하지 않았습니다.

| 구분 | 원본 | STEP 1 |
|---|---|---|
| UI | `<style>`, 폼, 결과 6개, 탭, 미리보기, 복사 | `index.html`, 원본 그대로 추출한 `styles.css`, `studio.js` |
| 인증 | 없음 | `account.js`, Firebase Auth Google/Email |
| API | `gen()`에서 Anthropic SSE 직접 호출, `searchNaver()` 직접 요청 | `api.js` → 인증 Callable. 외부 호출은 다음 단계까지 닫힘 |
| 프롬프트 | `buildPrompt()`, 스타일/SEO/JSON/사진 배치 | 서버 `prompt.js`에 보존, 미호출 |
| 상태 | `sT`, `sV`, `imgs`, `resultData` 전역 | UI 모듈 내부 상태 + IndexedDB 초안 |
| 비밀 | 브라우저 `jaeinit_claude_key`, `jaeinit_naver_id`, `jaeinit_naver_sec` | 입력 UI/직접 호출 제거, 해당 오래된 키만 삭제 |
| 글 저장 | localStorage 글·타입·날짜·결과만 저장 | 원본 유지 복사, 입력/사진 포함 IndexedDB + 명시적 서버 복사 |
| 다중 사용자 | 기기 전체 공유 목록 | 기기 보관함과 로그인한 회원 전용 목록 구분 |

CSS와 주요 폼/결과 마크업은 그대로 유지했습니다. 보안상 API 설정 모달은 계정 모달로 바꾸고, 헤더에 로그인/크레딧을 표시하며, 저장 탭에는 계정 복사·JSON 이동 기능을 추가했습니다. 저장된 장소/태그 등 결과가 HTML로 삽입되던 곳은 escape하여 저장형 스크립트 실행을 막았습니다.

원본 `gen()`의 SSE 호출은 브라우저 비밀키와 결합되어 있었습니다. '실제 AI 호출은 다음 단계'라는 범위에 맞춰 실제 요청은 제거했고, 생성 버튼은 인증된 서버 인터페이스를 호출합니다. STEP 1에서 새 AI 결과를 만드는 기능은 사용할 수 없으며, 기존 결과를 불러와 표시·미리보기·복사하는 기능을 검증합니다. 실제 API/SSE 재연결은 별도 단계입니다.

원본 파일은 이 프로젝트의 Hosting 결과물에 복사하지 않았습니다. 브라우저 키 입력/직접 API 호출 코드가 다시 배포되는 것을 방지합니다. 업로드 원본 자체는 변경하지 않았습니다.
